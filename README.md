# Offcut Desk

Open index.html in a modern browser. The project plans single-dimension timber cuts from a list of available remnants, then opens more stock only as required. It compares the plan against the same best-fit-decreasing heuristic starting with no offcuts. It shows each board, the cut sequence, the remaining length and saw kerf.

Use only stock of the same grade and cross-section. All lengths are whole millimetres. Every requested piece consumes one kerf. The algorithm does not claim an optimal solution. Fresh-board savings are calculated for the entered example, not observed workshop savings.
